# AlphaGrowth

AlphaGrowth is a crypto growth firm that grows protocols' TVL and liquidity and publishes free data.

**[Website](https://alphagrowth.io)** · **[Contact](https://alphagrowth.io/contact-us/)** · **[X](https://x.com/alphagrowth1)** · **[LinkedIn](https://www.linkedin.com/company/alphagrowth/)**

## Free crypto data

Projects, chains, fees and revenue, funding rounds and investors, DeFi yield pools, token unlocks, DAO treasuries and treasury companies. No API key, no sign-up. Every result carries a source block to cite.

- **MCP (Model Context Protocol) server** for AI agents: `https://alphagrowth.io/mcp`, 20 read-only tools. Setup for Claude, Cursor, VS Code and Gemini CLI in [alphagrowth-mcp](https://github.com/alphagrowth/alphagrowth-mcp).
- **Data API**: [`/api/v1`](https://alphagrowth.io/api/v1), described in [`/openapi.json`](https://alphagrowth.io/openapi.json).
- **For LLMs**: [`/llms.txt`](https://alphagrowth.io/llms.txt).
- **On the web**: [projects](https://alphagrowth.io/projects), [fees](https://alphagrowth.io/fees), [funding rounds](https://alphagrowth.io/recently-funded), [investors](https://alphagrowth.io/investors/), [token unlocks](https://alphagrowth.io/token-unlocks), [DAO treasuries](https://alphagrowth.io/dao-treasuries/).

```sh
claude mcp add --transport http alphagrowth https://alphagrowth.io/mcp
```
